    Why Claude Code gets its own page

    Anthropic publishes claude.ai, the Claude API, Claude Console and Claude Code as separate components, and they fail independently. Claude Code being broken while the chat interface is perfectly healthy is not an anomaly — it is the normal case, and it is exactly the situation where a headline “All Systems Operational” banner is least useful.

    So this page does one thing: it pulls the same official feed and reports Claude Code specifically, without averaging it against five other services you may not use. For the whole-platform verdict, the front page is the right place.

    It says operational but Claude Code still is not working

    Then it is very likely not an outage. In rough order of how often each turns out to be the cause: an expired login, a usage limit, a corporate proxy or VPN, an outdated CLI, or a hanging MCP server that stalls startup and looks exactly like the service being unresponsive.

    Two pages walk through it properly: Claude Code not working? Work down this list and Claude usage limits: why you hit them and when they reset.

    Worth knowing either way: status pages lag reality, routinely by ten to thirty minutes, because an incident is only posted once a human confirms it. Five minutes into a problem, trust your own failing requests over the green tick.
